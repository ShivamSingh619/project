# Phishing Campaign & Email Analysis

## Overview

This project documents a two-stage phishing investigation: analysing a phishing campaign, then examining an individual `.eml` email file in greater depth.

The investigation combines manual review with web-based analysis services and security tools to assess suspicious content and document supporting evidence.

## Project Scope

1. **Phishing Campaign Analysis**  
   Review the campaign’s messages, phishing indicators, and social engineering techniques.

2. **Individual Email Analysis**  
   Examine a selected `.eml` file, including its headers, sender details, message content, links, and attachments where present.

## Approach

- Manual inspection of email content and available metadata.
- Validation of suspicious indicators using websites and analysis tools.
- Documentation of findings, evidence, and investigation limitations.

## Skills Demonstrated

Phishing investigation, email analysis, social engineering assessment, indicator validation, and security documentation.

## Project Status

The campaign investigation and individual email analysis are documented as they are completed.
